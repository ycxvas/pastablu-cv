# pastablu-cv

Website CV / portfolio pastablu. Satu file `index.html`, tanpa build step.

## Jalankan lokal

Buka `index.html` di browser.

## Deploy

Aktifkan GitHub Pages: Settings → Pages → Branch `main` → folder `/ (root)`.

## Edit konten

- Portfolio: ganti tiga kartu "Segera hadir" di bagian `#work`.
- Foto profil: belum dipasang, bisa ditambahkan di bagian `#about`.
